- 🧭 **Reliable AI Agents** — orchestration, evidence boundaries, evaluation, and observability.
- 🔎 **Multimodal RAG** — turning complex research material into traceable knowledge.
- 🧰 **Agent tooling** — reusable MCP services and Agent Skills for practical workflows.

### A little about my work

- 🔬 Building scientific AI workflows around literature, knowledge retrieval, and evidence-grounded generation.
- 🌱 Learning how to turn AI Agent ideas into dependable engineering systems through internship practice.
